# Puisabpak NCR / CAPA eForm

ระบบบันทึกรายงานความไม่สอดคล้อง (NCR) และ CAPA ของโรงงานปุยแสบปาก ใช้คู่กับ SOP-QA-001

- `src/` หน้าจอ (React + Vite) ขึ้นใช้งานบน Cloudflare Pages
- `worker/` หลังบ้าน (Cloudflare Worker + ฐานข้อมูล D1 ชื่อ `puisabpak-ncr`)

## สิ่งที่ระบบควบคุม

| เรื่อง | การทำงาน |
| --- | --- |
| การเข้าใช้ | ต้องล็อกอิน บัญชีล็อก 15 นาทีเมื่อใส่รหัสผิด 5 ครั้ง เซสชันหมดอายุใน 12 ชั่วโมง |
| บทบาท | ผู้จัดการ QA, หัวหน้าทีมความปลอดภัยอาหาร (FSTL), QC, หัวหน้าแผนก, ดูอย่างเดียว |
| เลขที่เอกสาร | ระบบออกเอง `NCR-ปปดด-ลำดับ` และ `CAPA-ปปดด-ลำดับ` แก้ไขไม่ได้ |
| การตัดสินใจและทวนสอบ | เฉพาะผู้จัดการ QA และ FSTL ระบบบันทึกชื่อผู้ทำและเวลาให้ |
| การปิด NCR | เฉพาะผู้จัดการ QA และต้องมีข้อมูลครบ เมื่อปิดแล้วแก้ไขไม่ได้ เปิดใหม่ได้โดยระบุเหตุผล |
| ประวัติการแก้ไข | บันทึกทุกการเปลี่ยนแปลง ไม่มีคำสั่งลบ |
| ลิงก์ผู้ส่งมอบ | เปิดได้เฉพาะเอกสารฉบับเดียว เห็นและกรอกได้เฉพาะช่องที่กำหนด หมดอายุ 14 วัน |

## การติดตั้งครั้งแรก

ระบบนี้อยู่ในโฟลเดอร์ `ncr/` ของ repository `ra-application` และ deploy แยกจากแอป RA
(ไฟล์ `.github/workflows/ncr-deploy-worker.yml` และ `ncr-deploy-pages.yml`)

1. ที่ GitHub ไปที่ Settings → Secrets and variables → Actions แล้วเพิ่ม secret ชื่อ `SETUP_KEY`
   เป็นรหัสลับที่ตั้งเอง ยาวอย่างน้อย 20 ตัว ใช้ครั้งเดียวตอนสร้างบัญชีผู้จัดการ QA คนแรก
   (`CLOUDFLARE_API_TOKEN` และ `CLOUDFLARE_ACCOUNT_ID` ใช้ตัวเดียวกับแอป RA ที่มีอยู่แล้ว
   โทเคนต้องมีสิทธิ์แก้ไข Cloudflare Pages ด้วย)
2. เมื่อโค้ดเข้า branch `main` ระบบจะทดสอบและ deploy เอง (ดูผลที่แท็บ Actions)
3. เปิด `https://puisabpak-ncr.pages.dev/setup` กรอก Setup key แล้วสร้างบัญชีผู้จัดการ QA
4. เข้าสู่ระบบ แล้วเพิ่มผู้ใช้คนอื่นที่เมนูบัญชี → จัดการผู้ใช้

หาก Cloudflare ตั้งชื่อเว็บต่างจาก `puisabpak-ncr.pages.dev` ให้แก้ `ALLOWED_ORIGINS` ใน `ncr/worker/wrangler.toml` ให้ตรง
หากที่อยู่ของ Worker ต่างจากที่ตั้งไว้ ให้แก้ `VITE_API_URL` ใน `.github/workflows/ncr-deploy-pages.yml`

## ข้อมูลที่ต้องปรับให้ตรงกับโรงงาน

- `ncr/src/config.js` ชื่อบริษัทและรหัสแบบฟอร์ม
- `ncr/src/data/masterData.js` ขั้นตอนการผลิต พารามิเตอร์ รายชื่อผู้ส่งมอบ และผลิตภัณฑ์ (รายการปัจจุบันเป็นร่างเริ่มต้น)

## การทดสอบ

`cd ncr/worker && node --no-warnings test.mjs` ทดสอบหลังบ้านทั้งหมดกับฐานข้อมูลจำลอง (ต้องใช้ Node 22 ขึ้นไป)
