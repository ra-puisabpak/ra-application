# Regulatory Change Monitoring & Impact Assessment v1

## Purpose
Control the lifecycle from detection of an external regulatory update through screening, impact assessment, Change Control, implementation, and closure.

## Lifecycle
NEW → SCREENING → IMPACT_ASSESSMENT → ACTION_REQUIRED → IMPLEMENTING → IMPLEMENTED → CLOSED.

A change may be marked NOT_APPLICABLE when the documented assessment supports that conclusion.

## Impact assessment
The assessment records affected products, controlled documents, affected areas, rationale, assessor/date, and resulting Change Control references. The system must not infer impact from the source title alone.

## Change Control trigger
When an impact assessment identifies an impact, at least one Change Control reference is required before the assessment can be treated as resolved.

## Ownership and overdue control
Each monitored change may have an owner and due date. Overdue status is calculated from the due date and lifecycle status.

## Traceability
Regulatory Source → Regulatory Change → Impact Assessment → Change Control → Document Revision / Training / Product Update → Effective Implementation → Evidence → Audit.
